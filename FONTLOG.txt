FONTLOG for Apodi
=================

This file provides detailed information on the Apodi font software. This information should
be distributed along with the Apodi fonts and any derivative works.


Basic font information
----------------------

Apodi is an open, metric-compatible alternative to Aptos: a sans-serif family whose
characters have the same advance widths, kerning values and vertical metrics as Aptos, so
that documents keep their line and page breaks when Apodi replaces it. "Aptos" is used only
to describe compatibility (nominative use); Apodi is not affiliated with Microsoft.

Apodi is a Modified Version of Open Sans (designed by Steve Matteson; Open Sans Project
Authors), released under the SIL Open Font License 1.1, with 84 symbols and other scripts'
characters taken from Noto fonts (The Noto Project Authors, SIL OFL 1.1). Neither declares a
Reserved Font Name; the modified fonts are nevertheless renamed.

Families: Apodi, Apodi Narrow, Apodi Display; each in Regular, Bold, Italic, Bold Italic.

------------

substitution features):
  https://github.com/googlefonts/opensans
  commit bd7e37632246368c60fdcbd374dbf9bad11969b6 ("Fix version number to v3.003", 2023-11-16)

  https://github.com/google/fonts  commit 47d54ca1ebb14fd864695f1d39dc734f39017c33 (2026-10-16)
  ofl/notosans (Noto Sans 2.015, Italic), ofl/notosansmono (2.014), ofl/notosanssymbols
  (2.003), ofl/notosanssymbols2 (2.008), ofl/notosansmath (3.000), ofl/notosanscoptic (2.004),
  ofl/notosansarmenian (2.008), ofl/notosansarabic (2.012), ofl/notosansbengali (3.011),
  ofl/notosansgujarati (2.106), ofl/notosanstamil (2.004), ofl/notosansthai (2.002),
  ofl/notosanskhmer (2.004). Copyright 2022 The Noto Project Authors (notofonts/*); Noto Sans
  Math's name table reads "Copyright 2022 Google LLC".

Reference metrics (numbers only), read from locally installed Aptos fonts: advance width per
Unicode codepoint, advance per default-ligature character sequence, kerning value per
codepoint pair, unitsPerEm, hhea/typo/win ascender, descender and line gap, cap height,
weight class, italic angle, and the bounding boxes of the six box-drawing characters and the
two integral halves (so they join across lines). No outlines, points or curves were taken
from Aptos.


Changelog
---------

2026-10-17 (The Apodi Project Authors) Apodi v1.003
- Added the 84 characters of the reference that Open Sans lacks, with outlines from Noto
  (see Sources used): Coptic U+03E2-03EF; currency signs U+058F, U+060B, U+09F2, U+09F3,
  U+0AF1, U+0BF9, U+0E3F, U+17DB, U+20C0, U+FDFC; arrows U+2190-2199 and U+21A8; U+2219,
  U+221F, U+2229, U+2236, U+2261, U+2302, U+2310, U+2320, U+2321; circled digits U+2460-2469
  and U+2776-277F; box drawing U+2500, 2502, 250C, 2510, 2514, 2518; shapes U+25A1, 25AA,
  25AB, 25CB, 25CF, 25E6; U+2610, 2611, 2713, 2766, 27E8, 27E9, 2BBD, 2BBE.
- Each is scaled to Apodi's size, set to the style's stem weight (Noto's wght/wdth axes, or
  FreeType outline emboldening for the static Noto Sans Math, Symbols 2 and Coptic), slanted
  in the italics where the reference slants it, and given the reference's advance width
  (locked) and kerning. Box drawing and the integral halves run to the reference's bounding
  boxes so they join. U+21A8 is synthesized from Noto Sans Symbols' U+2195 plus a base bar.
- Apodi now covers all of the reference's characters.

2026-10-17 (The Apodi Project Authors) Apodi v1.002
- Outline changes only; metrics, kerning and line breaks unchanged against the reference.
- S and s: the 8's thin waist is replaced by a drawn spine, as thick as the bowls in every
  weight and flatter (33 degrees for S, 29.5 for s, judged against the reference's s), joining
  the bowls tangentially; the cuts are slightly smaller (S terminals at 29%/72% of the height,
  s at 32%/69%), so the terminals are longer and the openings narrower.
- k drawn with Open Sans's Cyrillic ka (U+043A), its stem extended to the ascender with a flat
  top as on l and h (in the italics, Open Sans's italic ka, the stem extended along the slant);
  k-cedilla and k-caron follow, Cyrillic ka itself unchanged.

2026-10-17 (The Apodi Project Authors) Apodi v1.001
- Outline changes only; advance widths, kerning, vertical metrics and ligatures unchanged
  (0 metric mismatches, 0 line-break differences against the reference).
- M: middle vertex raised to 25% of the cap height (was 16%).
- G drawn with Open Sans's Cyrillic Komi Sje (U+050C), K with Open Sans's Cyrillic Ka
  (U+041A); Latin names, kerning and groups kept.
- C and c cut out of O and o, S cut out of 8, s cut out of an x-height 8 (Open Sans's 8 at a
  heavier weight, scaled to the x-height): boolean differences with rectangles, giving flat
  horizontal terminals; the S cuts follow the 8's waist so the spine is one stroke. All
  styles.
- Italics: e, f, c, C, s, S, e-ogonek and the f ligatures are obliques (the matching roman
  glyph slanted by the italic angle) instead of Open Sans's cursive forms.
- Accented and other composites follow their redrawn base glyphs (marks move with anchors).

2026-10-17 (The Apodi Project Authors) Apodi v1.000
- Generated 12 static styles from the Open Sans Roman and Italic designspaces.
- Scaled all outlines uniformly by 1346/1462 (0.92066) so the cap height matches the
  reference; unitsPerEm stays 2048.
- Per glyph, interpolated Open Sans at the width (wdth 75-100, plus up to 6% horizontal
  stretch beyond wdth 100 and 3% compression below wdth 75) whose advance is closest to the
  reference advance, with the weight adjusted at every width so stem thickness stays
  constant (Regular from Open Sans wght 450, Bold from wght 700 at wdth 100). Composite
  (accented) glyphs follow their base glyph.
- Set every advance width exactly to the reference value by moving sidebearings (difference
  split in proportion to the existing left/right sidebearings). Symbols that would otherwise
  overlap their neighbours are scaled down uniformly (e.g. the registered sign).
- Replaced Open Sans's kerning with the reference pair values (class-compressed UFO groups,
  ignoring marks); mark positioning still comes from Open Sans's anchors.
- Default ligatures limited to ff, fi, fl (ffi, ffl removed from liga).
- Vertical metrics set to the reference values: hhea 1923/-577/0, typo 1923/-577/0,
  win 2068/563, USE_TYPO_METRICS on.
- Design changes:
  * M: middle vertex raised off the baseline by 16% of the cap height (parametric edit of
    Open Sans's M; carries into M-acute, Greek Mu, Cyrillic Em).
  * Open Sans alternates promoted to default where they match the reference's letter
    shapes: J sitting on the baseline (J.salt), and in italics the double-storey a (a.ss01).
    Former defaults stay available through salt/ss01/ss03. The double-storey (binocular) g
    remains the default, as in the reference; the single-storey g stays an alternate
    (salt/ss01/ss02).
- Hinting removed (unhinted TrueType, gasp: smoothing at all sizes).
- Unshipped glyphs pruned from the sources; glyph set = Open Sans's shipped set plus the
  extra Open Sans glyphs that cover reference characters (currency signs, Latin Extended-B,
  Greek symbols, format controls).
